The sequence representation problem

Genomic sequences are variable-length strings over small alphabets (DNA: {A,C,G,T}, protein: 20 amino acids). Standard ML expects fixed-size tensors. Three dominant strategies:

Strategy How it works Used by
k-mer / tokenizationSlide window of length k, map each k-mer to an integer ID; pad/truncate to fixed lengthDNABERT, Nucleotide Transformer, HyenaDNA
Character-level (byte/char)Each base = one token; sequence length = raw length; uses sub-quadratic attention (Hyena, Mamba, FlashAttention)HyenaDNA, Mamba, Caduceus
Fixed embeddings + poolingPre-trained embedding per k-mer/gene; aggregate (mean, attention) to fixed vectorgene2vec, scBERT (cell-level), earlier CNN work

Architecture families for sequence modeling

1. CNNs — Local motif detectors

Convolutions scan for position-invariant patterns (TF binding sites, splice sites). Dilated convolutions expand receptive field exponentially.

Input: [L, 4] one-hot ↓ Conv1d(k=15, dil=1) → ReLU ↓ Conv1d(k=15, dil=2) → ReLU ↓ Conv1d(k=15, dil=4) → ReLU (receptive field = 15 + 14×(1+2+4) = 113 bp) ↓ GlobalMaxPool → Dense → Task head

Strengths: Fast, interpretable filters → motifs. Limits: Fixed receptive field, weak long-range dependencies.

2. Transformers — Global context via attention

Self-attention relates every position to every other. Standard quadratic attention limits length (~4k–8k tokens). Genomics adaptations:

  • FlashAttention / xFormers: Exact attention, better memory, up to ~16k–32k
  • Linear/Performer attention: Approximate O(L), used in Nucleotide Transformer (12k context)
  • Hyena / Mamba (SSMs): Sub-quadratic, theoretically infinite context; HyenaDNA handles 1M bp

3. Hybrid CNN + Transformer

CNN stem for local feature extraction → Transformer for global reasoning. Enformer (Nature 2021) predicts expression from 200k bp using this pattern.

Self-supervised pre-training: the genomics unlock

Labeled data (e.g., "this variant is pathogenic") is scarce. Unlabeled sequences (reference genomes, SRA reads) are abundant. Pre-training objectives:

  • Masked Language Modeling (MLM): Mask 15% of tokens, predict them (BERT-style). DNABERT, Nucleotide Transformer.
  • Span masking / k-mer masking: Mask contiguous spans to force learning longer-range dependencies.
  • Contrastive / ESM-style: Predict masked residues in proteins; for DNA, predict masked bases across species alignments.
  • Next-token prediction (GPT-style): Autoregressive; used in HyenaDNA, GenomeLM.

Fine-tuning: Freeze backbone → train task head (linear probe) → optionally unfreeze last N layers. For small labeled sets (<1k), linear probe often beats full fine-tuning.

Evaluation pitfalls specific to genomics

Pitfall Why it matters Fix
Sequence homology leakageTrain/test share evolutionary history → inflated accuracyCluster at 30–50% identity; split by cluster, not random
Reference biasModels overfit to reference allele; miss alt allelesAugment with alternate haplotypes; test on diverse genomes
Class imbalance (rare variants)Pathogenic variants ≪ benign; accuracy misleadingUse AUPRC, balanced accuracy, F1; not AUROC alone
Batch effects / population stratificationTechnical artifacts correlate with labelsInclude covariates; adversarial debiasing; cross-cohort validation
