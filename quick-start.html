Central Dogma: The "Compile Pipeline"

Information flows one way (mostly): DNA → RNA → Protein

DNA (genome) → Transcription → pre-mRNA → Splicing → mature mRNA → Translation → Protein [Reference FASTA] (RNA pol II) (introns + (remove (exons only) (ribosome) (folded 3D) 3B bp human nucleus exons) introns) │ │ │ │ "Source code" "Executable" (static, same in (dynamic, cell-type every cell*) specific, regulated)

*Mostly true — immune cells rearrange DNA; somatic mutations accumulate.

DNA → Protein: The genetic code (lookup table)

Every 3 nucleotides (codon) = 1 amino acid. 64 codons → 20 amino acids + STOP. Redundant (degenerate).

Gene structure: Not a clean function definition

Genomic DNA (pre-mRNA): [Promoter]---[Exon1]---[Intron1]---[Exon2]---[Intron2]---[Exon3]---[PolyA signal] │ │ │ │ │ ▼ ▼ ▼ ▼ ▼ Transcription Splicing Splicing Splicing Cleavage + polyA │ │ │ │ │ ▼ ▼ ▼ ▼ ▼ Mature mRNA: [Exon1]===========[Exon2]===========[Exon3]---[poly-A tail] │ │ │ ▼ ▼ ▼ Translation Translation Translation (5' UTR) (CDS) (3' UTR)
  • Promoter: Upstream region where RNA polymerase binds (like a function decorator / entry point)
  • Exons: Coding sequences that remain in mature mRNA
  • Introns: Non-coding, spliced out (can be huge: 100s of kb)
  • UTR (Untranslated Regions): 5' UTR (regulatory, ribosome binding), 3' UTR (stability, localization)
  • Alternative splicing: Same gene → multiple protein isoforms (like polymorphic functions)

Concepts that break CS intuitions

IntuitionReality
"One gene = one protein"Human: ~20k genes → ~100k+ proteins (alt splicing, PTMs)
"DNA is the program"Epigenetics (methylation, histones) controls access; identical DNA → different cell types
"Sequence determines structure"Protein folding is physics; chaperones assist; misfolding = disease
"Mutation = bug"Most variants neutral; evolution needs variation; "bugs" can be features
"Reference genome = truth"Reference is one haplotype; you have two (diploid); population has millions of variants
"Gene = contiguous interval"Genes overlap, nest, read opposite strands; regulatory elements act at distance (enhancers)

One mental model to rule them all

Think of a cell as a massively parallel, stochastic, self-modifying distributed system:

  • Genome = source repo (but every cell has a copy)
  • Epigenetics = runtime config / feature flags (different per cell type)
  • Transcription = compilation (on-demand, regulated)
  • Splicing = link-time optimization (alternative isoforms)
  • Translation = execution (ribosomes = workers)
  • Protein folding = JIT optimization (physics-based, chaperone-assisted)
  • Protein function = API calls (binding, catalysis, signaling, structure)
  • Signaling = message passing between cells
  • Mutation = random bit flip in source (mostly caught by QC; some deploy to prod)
  • Evolution = continuous integration over billions of years (no rollback)
