Why AI + Genomics Now?

1

Data Explosion

Sequencing cost dropped ~100,000× since 2001. Public archives (NCBI SRA, ENA) hold petabases of sequence — far more than any human can analyze manually.

2

Compute + Algorithms

GPUs, Transformers, and self-supervised learning now scale to billion-sequence datasets. Models like HyenaDNA handle 1M bp context; ESM-2 learns from 65M protein sequences.

3

Clinical Pull

Rare disease diagnosis, cancer precision oncology, and population screening create massive demand for accurate, fast prediction. AI is moving from bench to bedside.

The field moves fast — models from 2022 are already superseded. This workshop emphasizes principles that outlast specific architectures.

Key Terminology Cheat Sheet

Term Meaning Why It Matters for ML
Read A short DNA sequence fragment from a sequencer (50–300 bp Illumina, 10k+ bp ONT/PacBio) Raw input tokens; error profiles differ by platform
Coverage Average reads per base; 30× = each base seen ~30 times Determines variant calling confidence; noise level
Reference genome High-quality assembly used as coordinate system (e.g., GRCh38) Alignment target; defines "normal" vs variant
Variant Difference from reference: SNV, indel, CNV, structural variant Prediction targets; most are benign, few pathogenic
Expression (RNA-seq) Measuring mRNA abundance per gene Quantifies which genes are active; regression/classification target
Embedding Dense vector representing a sequence, k-mer, or gene Learned so similar function → similar vector; transferable
Check Your Understanding

Why did deep learning take off in genomics around 2015–2017, not earlier? (Hint: it wasn't just "more data.")

Answer

Three convergent factors: (1) CNN architectures (DanQ, DeepSEA) showed regulatory prediction from raw sequence; (2) GPU compute became accessible for sequence-length inputs; (3) Self-supervised pre-training (k-mer masking, bidirectional LMs) let models leverage unlabeled data — critical because labeled genomics data is scarce. Data volume alone wasn't sufficient; the algorithmic toolkit to use it was missing.

Common Misconceptions

  • "Just more data" — but labeled data is still limiting; self-supervision was the unlock
  • "Just GPUs" — CNNs for sequences existed earlier but didn't generalize without architectural inductive biases (dilated convs, attention)
  • "Transformers arrived then" — Transformers came later (2019+); the 2015–2017 wave was CNN/RNN-based
